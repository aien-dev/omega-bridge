- Never imply CPU simulator evidence is GPU or general CUDA C++ qualification.
- No nvcc/Clang/C++ parser/runtime in construction; g++ only independent oracle.

- Work is local isolated candidate; no service, driver or global-install changes.

## Review Focus
- C++ translation phases: reject backslash, preprocessing, NUL, non-ASCII code and trigraphs rather than changing meaning.
- Lexical shadowing and identifier collisions: resolve all names, refuse duplicates.
- Uint32 expression precedence and wrap after each operation.
- Exact source/input capacities, depth, truncation, trailing data and output transactionality.
- Explicit target choice and safe output/alias/install lifecycle.
