# MAX version metadata regression, 2026-10-30

Status: EXERCISED_HOST for metadata only. Base:
`1958a1895279c0d4869bab39eaa20f070b174a6c`. Host: Linux x86_64,
Python 3.12.14. MAX is not installed. Existing evidence is unchanged.

## Change

`_max_version()` used to return the requested release `26.7.0` when imported
MAX had no `__version__`. Missing metadata is not evidence of an installed
release. The helper now reports `unknown` for absent, unreadable or invalid
metadata and preserves observed nonempty string versions.

The regression test loads the actual runner with import-only module doubles.
Constructing a MAX graph, session, buffer or device raises in those doubles.
This tests metadata, not MAX execution, binary compatibility or GPU behavior.
`conformance/run.sh` invokes it before fixture generation or build effects.
